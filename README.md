# Control de asistencia

Aplicación Flutter  para registrar la asistencia de estudiantes.

## Funciones

- Mostrar una lista de estudiantes.
- Marcar o quitar la asistencia.
- Mostrar el total de estudiantes presentes.
- Reiniciar todas las asistencias.

## Ejecución

Instala Flutter y ejecuta:

```bash
flutter pub get
flutter run
